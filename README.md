# APR_Mini_Project_Next_Word_Predictor
This project is a simple implementation of an LSTM neural network to predict the next word in a sequence.
It was built using PyTorch.
Process:-> Loading the Data -> Preprocessing -> Building Sequences -> Defining the Model -> Training
Accuracy we achieved is 97.19

Steps to run the code:
1. Clone this repository.
2. Install the required packages: pip install -r requirements.txt
3. Run the Jupyter Notebook: APR_Next_Word_Predictor.ipynb
